# 轻划 · Trackpad Flow

为 Mac 妙控触控板和内置触控板开发的窗口管理工具，支持多指滑动、三指捏合缩放与四角轻点。本地测试版 0.3.2，Swift / SwiftUI / AppKit，无第三方运行时依赖。

## 从源码开始

需要 Mac、Apple Command Line Tools（或完整 Xcode）以及 Swift 5.9 或更新版本。先在解压或克隆后的项目根目录执行：

```sh
# 尚未安装开发工具时执行；按系统提示完成安装。
xcode-select --install

# 已安装开发工具时从这里开始。
zsh scripts/test.sh
zsh scripts/build-app.sh
open dist/轻划.app
```

源码包不包含 `.build/` 编译缓存、`dist/` 应用包或已生成的 ICNS／iconset；构建脚本会从 `Assets/AppIcon-source-v1.png` 重新生成图标并打包应用。无需第三方包、API 密钥或付费开发者证书；当前脚本使用本地 ad-hoc 签名。

项目结构：`Sources/TrackpadFlow/` 为 Swift 应用，`Sources/TrackpadBridge/` 为 C 触控板桥接，`Tests/` 为测试，`scripts/` 为构建与测试入口，`Assets/` 为图标原图和生成说明。上传 GitHub 的步骤见 [GITHUB.md](GITHUB.md)。

## 打开应用

应用位置：`dist/轻划.app`。双击启动，设置窗口会打开，Dock 显示应用图标，菜单栏保留手势图标。关闭设置窗口后应用继续运行并留在 Dock；点击 Dock 图标可重新打开设置，也可恢复最小化的设置窗口。按 Command-Q 或从菜单选择“退出轻划”可完全退出。若希望退出后也固定在 Dock，可右键图标 → 选项 → 在程序坞中保留。

构建脚本在签名验证完成后刷新本应用的 Launch Services 注册。更新图标后，如果系统设置中的权限列表仍显示旧占位图标，请退出并重新打开系统设置，再进入对应权限页面；无须为刷新图标切换权限开关。

第一次打开默认为**测试模式**，先验证多指数据，再授予窗口控制权限并开启。每次重新启动都会回到测试模式，防止未完成手势配置时直接控制窗口。

### 首次配置

1. 在“手势与窗口”页面，把三个手指放在触控板上，检查实时预览和帧计数；向四个方向滑动，检查识别结果。
2. 为避免系统与本应用同时执行手势，在系统设置 → 触控板 → 更多手势中，将三指“在全屏幕应用程序之间轻扫 / 调度中心 / App Exposé”改为四指，或关闭对应手势。不同 macOS 版本名称可能略有差异。
3. 在系统设置 → 辅助功能 → 指针控制 → 触控板选项中，关闭“三指拖移”，或改用其他拖移方式。若其他手势软件也占用了三指，请调整它的对应绑定。
4. 在本应用“权限与帮助”中打开辅助功能设置，为**轻划**开启权限。此权限允许轻划移动和调整其他应用的窗口；应用不会自动代你开启。
5. 如果没有触控数据，在“权限与帮助”打开输入监控设置，为轻划开启权限，再重新连接触控板；必要时退出重开应用。权限状态为“待检查”不一定代表触控数据不可用，以实时测试为准。
6. 返回“手势与窗口”，点击“开启窗口手势”。切换到 Finder 等可调整大小的普通窗口，再执行手势。

也可以在本应用选择四指模式，但需关闭系统对应的四指手势。

## 默认手势

| 手势 | 动作 |
| --- | --- |
| 三指向左滑 | 左半屏 |
| 三指向右滑 | 右半屏 |
| 三指向上滑 | 最大化到可用桌面，保留菜单栏和 Dock |
| 三指向下滑 | 最小化当前窗口到 Dock |

方向按手指在触控板上的物理移动判断，不受“自然滚动”方向影响。一次连续接触最多触发一次动作，抬手后才可再次触发。支持自定义方向映射、三指或四指、滑动距离和窗口间距。

其他可选动作：恢复原位、上半屏、下半屏、居中、移到下一显示器、切换同应用的普通窗口、不执行。窗口目标为手势开始时处于前台的应用；若滑动中前台应用改变，会跳过本次操作。

0.1.1 首次启动会将已有配置的下滑动作更新为最小化，保留其他方向的绑定；之后仍可自行更改。最小化不要求窗口支持调整大小，但需要窗口本身提供最小化接口。

“仅测试手势”开启后继续识别和显示结果，但不执行窗口或桌面动作。测试区坐标、帧数和结果仅存在内存中；偏好设置保存手指数、方向映射、滑动距离、窗口间距、四角开关与区域，以及捏合开关和灵敏度。

## 三指捏合缩放窗口

侧栏“捏合缩放”提供开关、实时接触预览、缩放比例和灵敏度（0.5×–2.0×）。三指捏合默认开启；仍需开启全局窗口控制，并关闭“仅测试”，才会实际调整窗口。

- 三根手指留出间距，向内收拢：缩小当前应用窗口。
- 三指向外张开：放大当前窗口。
- 不抬手时可连续调整，也可中途反向；抬起任一手指后结束本次缩放，保留当前大小。所有手指抬起后才能开始下一次。
- 三指一起平移仍用于原有滑动操作。通过手指间距离变化识别捏合，同一轮接触锁定为滑动或捏合，避免连续触发两类动作。
- 即使滑动模式选为四指，捏合始终使用三指。两指捏合不用于窗口缩放。

尺寸依据本次捏合开始时的窗口大小计算，不逐帧累乘。保留窗口原始宽高比例，尽量固定中心，并约束在当前显示器的可用桌面内；实际位置或比例仍可能受应用的尺寸限制影响。写入窗口尺寸最多每秒 30 次；该值不是实际帧率保证。

默认几何下限为宽 240 pt、高 160 pt（原窗口或显示器更小时相应调整），应用自身的最小尺寸可更大。系统全屏或固定尺寸窗口无法缩放。前台窗口改变、额外手指加入、接触 ID 改变或输入中断时，会停止本次缩放，保留最近已应用的大小。恢复原位记录仍可通过自定义“恢复原位”动作使用。

先在测试模式确认“向内／向外”及百分比反馈，再开启控制。若三指拖移或其他手势软件占用此手势，请调整对应配置。

## 四角轻点

这里的四角指**触控板本身**的四角。单指轻触并在 0.3 秒内抬起，无需按下触控板。

| 触控板位置 | 动作 |
| --- | --- |
| 左上角 | 最大化当前窗口 |
| 右上角 | 最小化当前窗口 |
| 左下角 | 关闭当前窗口 |
| 右下角 | 显示桌面，再次轻点切回 |

打开侧栏“四角轻点”，在预览图或下方按钮中选一个角。每个角的区域宽度、高度都可以独立设置为整块触控板的 5%–45%，默认宽 18%、高 22%；每个角也可单独关闭，或使用总开关关闭四角功能。范围固定在对应角落，最大值保证四角不会重叠。设置自动保存在本机。

轻点必须从区域内部开始、保持在内部并抬起；移动超过约 2.5% 的标准化坐标、长按、多指操作或移动进入角落不触发。新增手指后，即使只剩一指，也要全部抬起才能开始新一次轻点。

关闭调用窗口自身的关闭按钮；如果文档未保存，由原应用显示保存提示，不自动选择或强制退出。显示桌面使用系统“显示桌面”快捷键；读取已配置的组合，没有覆盖设置时使用 Fn-F11。若系统禁用了此快捷键，应用会提示在系统键盘快捷键中启用。

启用控制后，应用会通过仅监听鼠标左键事件的过滤器，尝试拦截角落轻点同时产生的普通点击，避免点到下方窗口。测试模式不拦截点击；过滤器未能启动时四角只允许测试，不执行动作。四角预留给快捷动作，普通点击建议使用触控板中间区域。该过滤与实际硬件时序仍需授权后的端到端实测。

## 已知边界

- 全局原始多指识别依赖 macOS **非公开** `MultitouchSupport.framework`，通过 `dlopen` / `dlsym` 动态加载。Apple 没有稳定性保证；macOS 升级后可能需要适配接触结构和函数签名。当前交付是本地测试应用，没有 Developer ID 公证，也未经过 App Store 审核。
- 本版**不会屏蔽或修改系统三指／四指手势**，必须按上述步骤处理冲突。输入监控和辅助功能权限也不能自动替代系统手势配置。
- 桥接会监听系统枚举到的多点触控设备。设备数不等于已确认兼容的触控板数量；必须看到实时接触数据，才说明该设备实际提供了当前版本能解析的输入。
- 系统全屏、最小化窗口、固定大小窗口、特殊对话框，以及未提供窗口辅助功能接口的应用，可能无法调整。部分应用强制最小窗口尺寸，半屏时可能超出目标；界面会提示受尺寸限制。
- 最大化不等于系统全屏。恢复位置记录仅在本次进程内有效；退出应用后清除。最多保存 100 个窗口；显示器断开后恢复位置会限制在当前可用屏幕范围内。
- 切换窗口仅针对同一应用的普通非最小化窗口，不跨应用或切换 Space。
- 每 5 秒重新枚举设备，并在睡眠唤醒后重新建立监听。蓝牙重连后若没有接触数据，可手动“重新连接触控板”。
- 系统鼠标事件没有在本实现中提供可靠的物理设备标识。若一只手正在轻触触控板角落、另一只手同时使用外接鼠标，外接鼠标的点击也可能被过滤；避免同时操作这两种输入设备，或关闭四角功能。
- 本构建针对 Apple Silicon；最低部署版本为 macOS 13，但实际兼容性仅以测试记录中的系统为准。

## 构建与验证

需要 Apple Command Line Tools 和 Swift 5.9 或更新版本。

```sh
zsh scripts/test.sh
zsh scripts/build-app.sh
./dist/轻划.app/Contents/MacOS/TrackpadFlow --probe
open dist/轻划.app
```

`--probe` 仅检查框架加载、设备枚举和权限状态，不请求权限、不移动窗口。单元测试验证方向识别、单次触发、抬手、手指增减、误触和多显示器几何。`scripts/test.sh` 用 Command Line Tools 运行相同的测试案例；安装完整 Xcode 后也可使用 `swift test`。真实触控板到真实窗口的端到端验证需要在本机授予权限并实际滑动；自动化测试不能替代这一步。
